# Тросовая система перемещения (CDPR)

Управление платформой на 4 тросах: движение по G-code, ручной джог, ручное
перемещение «за руку», управление натяжением, автокалибровка и веб-панель.

Железо: сервоприводы HLTNC T3D (HL-T3D-L20A-RABF) с двигателями
80AST-A1C04025Z1 (1 кВт, 4 Н·м, абсолютный многооборотный энкодер 23 бита),
связь Modbus RTU по RS-485.

## Как это устроено

Три слоя, каждый заменяется независимо:

    Transport   как байты ходят до устройства   drives/modbus_rtu.py, drives/sim.py
    Drive       что означают регистры привода   config/drive_t3d.yaml (данные, не код)
    DriveGroup  как опросить все оси за цикл    drives/base.py

Всё настраиваемое живёт в YAML. Поддержать другой привод — положить рядом ещё
один профиль. Поменять геометрию или число тросов — поправить `machine.yaml`.
Python при этом не трогается.

    config/machine.yaml     геометрия, лебёдки, лимиты, натяжение, шины
    config/drive_t3d.yaml   карта регистров привода
    cdpr/                   кинематика, управление, режимы
    drives/                 транспорт, драйверы, симулятор, разведка
    tools/                  утилиты для гаража
    tests/                  прогоняются без железа

## Запуск

Полностью рабочая система на модели, железо не нужно:

    python run.py --sim

Панель откроется на http://localhost:8000/ — там платформа висит на четырёх
упругих тросах, приводы отвечают с задержкой, момент считается из настоящих
натяжений. Осваиваться стоит здесь.

Репетиция утилит для гаража:

    python tools/bus_scan.py --sim
    python tools/reg_probe.py --sim

На железе:

    python tools/bus_scan.py --list-ports
    python tools/bus_scan.py --port COM3
    python tools/reg_probe.py --port COM3 --slave 1 --apply
    python run.py

Тесты:

    python -m pytest tests/ -q

## Что нужно сделать на железе до запуска движения

1. Выставить на панели каждого привода разные адреса `P-181` (1..4) и скорость
   `P-182 = 5` (115200). Из коробки стоит 19200 и адрес 1 у всех — на такой
   шине связи не будет вовсе.
2. Прогнать `tools/reg_probe.py` и получить карту регистров: без неё драйвер
   осознанно отказывается работать с железом.
3. Убедиться, что уставка скорости не пишется в EEPROM (это проверяет тот же
   `reg_probe`). Если пишется — цикл 50 Гц выведет привод из строя примерно
   за полчаса, и нужно искать диапазон-зеркало.
4. Завести вход SON всех приводов в одну цепь через реле — это аппаратный
   аварийный стоп, не зависящий от софта.
5. Ограничить момент в самих приводах: при 4 Н·м и барабане ⌀60 полный момент
   даёт 132 Н на тросе, чего достаточно, чтобы порвать слабое звено.

Подробности найденного по ходу работы — в `docs/NOTES.md`.
